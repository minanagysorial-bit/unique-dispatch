## 🚀 Key Features

1. **Enterprise Logistics Web Platform:**
   - Modern, high-converting responsive web application tailored for US freight carriers and owner-operators.
   - Clean, professional 24/7 operations desk contact infrastructure.
   - Integrated live chat, fast quote submission, and WhatsApp connectivity.

2. **Core Freight & Amazon Relay Services:**
   - Amazon Relay middle-mile optimization, spot monitoring, Post-A-Truck (PAT), block bookings, and ROC delay dispute handling.
   - Semi-Truck & Box Truck Dispatch (Dry Van 53', Reefer 53', Flatbed / Step Deck, 26ft Box Trucks, Power Only).
   - Aggressive Rate-Per-Mile negotiation and broker credit vetting.
   - Back-office paperwork offloading (Carrier setup packets, NOAs, factoring submissions, detention/layover billing).

3. **Interactive Rate & Earnings Calculator:**
   - Dynamic real-time revenue projection tool based on equipment type, fleet size, weekly miles, and pricing plan.

4. **Transparent Pricing Models:**
   - **Plan A (Percentage):** 6% of gross load revenue (ideal for owner-operators).
   - **Plan B (Flat Fee):** $299 / week per truck (fixed rate for fleets).
   - 100% No Forced Dispatch policy guarantee.

5. **Full Carrier Onboarding Form:**
   - Responsive multi-field intake form for MC/DOT numbers, equipment type, contact info, and preferred lanes.

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Open in browser
http://localhost:3000
```

---

## 📦 Production Build & Vercel Deployment

```bash
# Run production build
npm run build

# Start production server
npm start
```

### 1-Click Vercel Deployment:
1. Push repository to GitHub/GitLab.
2. Import repository into [Vercel](https://vercel.com).
3. Framework Preset will automatically detect **Next.js**.
4. Click **Deploy**. No additional environment variables required.
